# 0003. Générateur : Astro 7

**Statut :** accepté, novembre 2026.

## Contexte

Il faut un générateur conçu pour les sites de contenu, qui valide les données au build et n'envoie pas de JavaScript inutile. Astro 6 avait été retenu au départ. Au moment de construire le socle (novembre 2026), la branche 6 ne reçoit plus de correctifs depuis la version 6.4.8 (juin 2026) ; Astro 7 est la version maintenue.

## Décision

Le site est généré avec **Astro 7**, en sortie 100 % statique. Version épinglée dans `package-lock.json`.

## Alternatives écartées

- Astro 6 : plus de correctifs, y compris de sécurité.
- Next.js : orienté serveur, surdimensionné pour ce site.
- Eleventy : très stable, mais sans validation typée intégrée.
- Docusaurus, VitePress : gabarits de documentation, trop contraignants pour des visuels sur mesure.

## Conséquences

- Aucun JavaScript envoyé par défaut ; collections de contenu validées par schéma au build ; polices auto-hébergées ; sortie statique.
- Risque assumé : Astro appartient à Cloudflare depuis janvier 2026. La séparation entre données et affichage limite ce risque : seule la couche `src/` serait à réécrire.
